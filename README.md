# LRAPA

Long-read Alternative Polyadenylation (LRAPA) is an R package specifically designed for comprehensive analysis of alternative polyadenylation (APA) using both bulk and single-cell long-read RNA sequencing data. The package enables the identification and quantification of polyadenylation sites, supports differential APA analysis between conditions and cell types, and facilitates the analysis of polyadenylation site (PAS)-exon and transcription start site (TSS) couplings. LRAPA provides a robust framework for uncovering the regulatory complexity of APA in diverse biological contexts.
