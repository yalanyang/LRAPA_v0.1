# **Step 3. PAS count**
After identifying the genomic coordinates of PAs, each long read was assigned to an annotated PA. If the last mapped base of a long read fell within a PA region, the read was considered to use that PA. This approach allowed us to count the number of long reads supporting each PA in each sample or cell. 

## 3.1 Bulk long-read RNA-seq

``` shell
lrapa count -b N1.bam,N2.bam,C1.bam,C2.bam -p test.PAS.bed -o test.PAS.count.txt
```

**Parameters**

-   `-b, --bam_files`: Comma-separated list of input BAM files (required).
-   `-p, --pas`: PA reference TXT file with BED columns followed by annotations (required), generated by anno function.
-   `-o, --output`: Output text file for the count matrix (required).


The output is a PA-by-sample count matrix with annotation information.

## 3.2 Single-cell long-read RNA-seq

``` shell
lrapa scCount -b scLR.bam -p test.PAS.bed -o test -w barcode.txt
```

**Parameters**

-   `-i, --input`: Input scRNA-seq BAM file (required).
-   `-p, --pas`: PA reference TXT file with BED columns followed by annotations (required).
-   `-o, --output`: Output folder for the count matrix (required).
-   `-w, --barcode`: Barcode file.

The output is a PA-by-cell (barcode) count matrix compatible with Seurat package for downstream single-cell analyses.
